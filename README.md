# 澈宸杯海选比赛服务器
Java 编写，基于 [jphira-mp](https://github.com/lRENyaaa/jphira-mp) 和 [jphira-mp-protocol](https://github.com/lRENyaaa/jphira-mp-protocol)

ccc-qq-robot文件夹下是 QQ 机器人 用于 QQ 绑定
基于 [Shiro](https://github.com/MisakaTAT/Shiro) 框架开发
使用llonebot协议 可在 [此处](./ccc-qq-bot/src/main/resources/application.yml) 修改连接配置

日志StripAnsi实现和配置文件来自 [Velocity](https://github.com/PaperMC/Velocity)
